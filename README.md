# PizzaPoint


## Возможности

- регистрация;
- вход;
- проверка доступа к админ-панели;
- просмотр меню и фильтрация по категориям;
- корзина;
- оформление заказа и просмотр истории заказов;
- администратор управляет пиццами и категориями, просматривает заказы и меняет их статусы;


## Запуск

1. Установите Python 3.10+.
2. Откройте папку проекта в терминале.
3. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

4. Запустите приложение:

   ```bash
   python app.py
   ```

5. Перейдите на http://127.0.0.1:5000.

## Структура базы данных

- `users` — учетные записи и роли;
- `customers` — данные клиента (связь 1:1 с `users` через `user_id`);
- `categories` — категории меню;
- `products` — пиццы (FK `category_id` на `categories.id`);
- `cart_items` — позиции корзины (ссылки на клиента и продукт);
- `orders` — заказы (FK `customer_id` на клиента);
- `order_items` — состав заказа (FK на заказ и продукт; цена и название сохраняются на момент оформления).


## Файлы

- `app.py` — маршруты сайта, регистрация, вход, корзина, оформление и кабинет;
- `auth.py` — текущий пользователь, декоратор проверки ролей, CSRF;
- `db.py` — подключение, транзакции, начальные данные и администратор;
- `admin.py` — функции административной панели;
- `schema.sql` — таблицы и связи;
- `templates/` — HTML-шаблоны;
- `static/` — стили и JavaScript.
